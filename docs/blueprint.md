# **App Name**: MyLaunch MVP

## Core Features:

- Smart Home Screen: Home screen with a clear display of projects and personalized widgets.
- AI Copilot: AI copilot providing context-aware suggestions for idea naming, feature planning, and content generation using custom dynamic prompts.
- Launch Workspace: Create workspace for managing ideas, building MVPs, and tracking progress visually.
- Launch Studio: Simple launch studio to deploy a landing page with pre-built templates.
- AI-Guided Notifications: Notifications providing AI-guided personalized reminders to users
- Personalized learning: AI tool will analyzes user content (ideas, descriptions, goals) to recommend personalized learning paths with micro-lessons to help achieve the best outcome

## Style Guidelines:

- Primary color: Deep violet (#6C4AB6) for innovation and futuristic feel.
- Background color: Very light violet (#F2EEFA) for clean, premium appearance.
- Accent color: Soft blue (#4A86B6) for highlighting interactive elements.
- Body and headline font: 'Inter' (sans-serif) for a modern, neutral look, which matches well to highly technical material and also functions well for large blocks of text
- Custom icons for key features, ensuring a clean, minimalist design.
- Clear, card-based layouts that are easy to navigate on mobile devices.
- Subtle animations to enhance the user experience with smooth page transitions.
